# Assignments App

A study app with assignment question sets for subjects such as Digital Logic, C Programming, IIT and Physics.

> Built in 2021–2022 while I was learning Flutter and mobile development in Nepal. Kept here as part of my learning history.

## Features
- Question sets per subject
- PDF viewer and links to video lessons
- Ad-supported (AdMob)

## Run it
Requires the [Flutter SDK](https://docs.flutter.dev/get-started/install).
```bash
flutter pub get
flutter run
```

## Tech
Flutter · Dart · PDF viewer · HTTP · AdMob
